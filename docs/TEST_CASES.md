# IsaacDanmaku 测试用例

> 最后更新：2026-08-11

## 自动化

`lua tests/run.lua`覆盖：

- 设置枚举回退、旧/损坏存档恢复、透明度和同屏数量边界；
- 配置菜单注册与透明度滑杆端点；
- 新局/续局、Boss、隐藏房、受伤、换层和死亡场景映射；
- 换层时原生回调的反向顺序归一化；
- `F1/H3`与`C8/H5`共享事实但不重复评论；
- RunContext状态更新与重置；
- 稳定文案选择、全局节流、单局次数和内置规则覆盖率；
- 弹幕队列上限、关键消息抢占、轨道复用和清理。

## Repentance+ 实机验收

| ID | 场景 | 预期 |
|---|---|---|
| MOD-001 | Workshop首次订阅并启用 | 无额外程序即可进入一局，日志无Lua错误 |
| MOD-002 | 新局与继续游戏 | 分别触发H1/H2且每局最多一次 |
| MOD-003 | 换层 | 更新上下文，只显示F1一条弹幕并记录H3 |
| MOD-004 | 普通房、Boss与清房 | 分别触发A1/A3/A9，回调后下一渲染帧入队 |
| MOD-005 | 六类特殊房 | 宝箱、商店、恶魔、天使、献祭、隐藏房映射F2–F7 |
| MOD-006 | 受伤与死亡 | C1按冷却输出；死亡只显示C8并记录H5 |
| MOD-007 | 通关 | 显示H6且停止本局后续事件 |
| UI-001 | 未安装配置菜单 | 使用默认设置，核心功能正常 |
| UI-002 | 安装中文版配置菜单 | 九项设置可修改并跨重启保存 |

## 发布门槛

- Lua自动化全部通过；
- `metadata.xml`、字体、OFL许可证和全部运行模块进入发布目录；
- M0每个可评论场景至少有三人格文案；
- 30分钟普通频率目标为6–12条非重复弹幕；
- 不存在Python、Node、Rust、截图、网络或数据库运行依赖。
