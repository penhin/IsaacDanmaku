# IsaacDanmaku Chinese bitmap font

`isaac_danmaku_zh.fnt` and `isaac_danmaku_zh_0.png` are a glyph subset generated from
Noto Sans CJK SC Regular. The `.fnt` shipped to the game uses BMFont Binary v3,
which Repentance+ requires. `isaac_danmaku_zh.fnt.txt` retains the equivalent
text descriptor for glyph coverage tests. Only glyphs used by the bundled
IsaacDanmaku interface and comments plus printable ASCII are included.

The source font is published by the Noto project under the SIL Open Font
License 1.1. The generated bitmap font remains under that license; see
`OFL.txt`. Source: https://github.com/notofonts/noto-cjk
